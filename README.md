# סאונד והגברה

יישום סטטי בעברית לקורס סאונד והגברה. מבוסס על JavaScript ו־Vite, ללא שירותי שרת. הגופן Heebo נכלל בבנייה ומוגש מקומית.

## הפעלה

```sh
npm install
npm run dev
```

## בנייה

```sh
npm run build
npm run preview
```

הקבצים לפרסום נוצרים בתיקיית `dist`. באחסון סטטי יש להגדיר החזרת `index.html` עבור נתיבים שאינם קבצים כדי שפתיחה ישירה ורענון של `/lessons` ושל `/lessons/1` יעבדו. שרתי Vite המקומיים כוללים התנהגות זו.

## מבנה

- `src/main.js` — ניווט באמצעות History API, לרבות אחורה וקדימה בדפדפן וניקוי הפעילות ביציאה.
- `src/pages.js` — עמוד פתיחה ורשימת שיעורים.
- `src/components.js` — מבנה עמוד משותף, כרטיס שיעור ואיורי SVG.
- `src/data/lessons.js` — פרטי השיעורים.
- `src/styles.css` — עיצוב רספונסיבי. כיווניות ושפה מוגדרות ב־`index.html`.

- `src/lesson1/` — עמוד השיעור, יצירת שאלות, תרגולים ועיצוב הפעילויות.
- `src/shared/presentation-viewer.js` — מציג תמונות לשימוש חוזר, עם ניווט מקלדת ומסך מלא.
- `src/audio/tone-engine.js` — מנוע גלי סינוס משותף לכל התרגולים.
- `assets/lesson1/` — 11 השקופיות המקוריות; נטענות לפי סדר מספרי ללא שינוי בתמונות.

## שיעור 1

- `/lessons/1` — בחירת פעילות.
- `/lessons/1/presentation` — מצגת; חץ שמאלה לשקופית הבאה וחץ ימינה לקודמת. בדפדפן ללא תמיכה במסך מלא, המצגת נפתחת על כל שטח החלון.
- `/lessons/1/exercises/1` — זיהוי טווח גובה הצליל.
- `/lessons/1/exercises/2` — השוואת שני תדרים בהפרשים מצטמצמים.
- `/lessons/1/exercises/3` — זיהוי תדרים מתוך ארבע אפשרויות.

בכל תרגול עשר שאלות, משוב מיידי, ניקוד ותרגול חוזר. כל הפעילויות פתוחות לגישה ישירה. התקדמות וניקוד נשמרים בזיכרון הפעילות בלבד ומתאפסים בכניסה מחדש. אישור תזכורת השמיעה נשמר ב־`sessionStorage` למשך סשן הלשונית; אין חשבונות, שרת או שמירת ציונים.

השמע מתחיל רק בלחיצה על כפתור השמעה. כל צליל נמשך שנייה אחת, בעוצמת gain קבועה של 0.035, עם כניסה של 35 אלפיות שנייה ויציאה של 80 אלפיות שנייה. החלפת צליל מפסיקה את קודמו בהדרגה. ניווט, מעבר ללשונית אחרת ויציאה מהעמוד מפסיקים את השמע; יציאה מפעילות גם סוגרת את הקשר השמע. אין הגברה אוטומטית או איזון עוצמה שמעלה את העוצמה בתדרים קיצוניים.

## שיעור 2 — האוזן האנושית והשמיעה

- `/lessons/2` — בחירת פעילות עצמאית, ללא נעילת תרגולים.
- `/lessons/2/presentation` — תשע תמונות המקור מתוך `assets/lesson2`, בסדר מספרי טבעי ובמציג המשותף לשיעור 1.
- `/lessons/2/exercises/1` — חתך SVG סכמטי עם שש תחנות לבחירה בלחיצה או במקלדת, משוב ואנימציית מסלול. האיור מציג את מסלול השמיעה בלבד, ללא מערכת שיווי המשקל ותעלת האוורור.
- `/lessons/2/exercises/2` — אשליית שפרד הנוצרת מקומית באמצעות Web Audio, ללא קובץ שמע חיצוני. ההסבר והגרף האינטראקטיבי נחשפים רק אחרי האזנה ובחירת תשובה.
- `/lessons/2/exercises/3` — חמישה מצבי שמירה על השמיעה, משוב מיידי ותרגול חוזר.

קוד הפעילויות נמצא ב־`src/lesson2`; הטקסטים והמצבים נמצאים בנפרד ב־`data.js`. מנוע האשליה נמצא ב־`src/audio/shepard-engine.js`. הוא מחבר שישה רכיבים במרווחי אוקטבה, עם מעטפת עוצמה קבועה על ציר תדר לוגריתמי. 24 צעדים בני 0.32 שניות יוצרים שני מחזורים זהים של 12 חצאי טון, במשך 7.68 שניות. סכום אמפליטודות הרכיבים מוגבל ל־0.035; לכל צעד כניסה ויציאה הדרגתיות. אין שינוי בעוצמת המכשיר. הפעלה דורשת לחיצה; עצירה, יציאה מהפעילות או מעבר ללשונית אחרת מנתקים את האות. היציאה מהפעילות סוגרת גם את הקשר השמע.

מקורות לתוכן ולמודל: [מסלול השמיעה — המכון הלאומי האמריקאי לחירשות ולהפרעות תקשורת](https://www.nidcd.nih.gov/health/how-do-we-hear), [צלילי שפרד — אוניברסיטת קליפורניה בסן דייגו](https://musicweb.ucsd.edu/~trsmyth/stream175/Shepard_Tones.html), [האזנה בטוחה — ארגון הבריאות העולמי](https://www.who.int/news-room/questions-and-answers/item/deafness-and-hearing-loss-safe-listening).

## שיעור 3 — מפת המיקס – Billie Jean

אפשר להיכנס דרך הכרטיס השלישי ב״השיעורים שלנו״ או ישירות ב־`/lessons/3`. זהו מרחב יצירה אחד לשיר כולו, ללא חלוקה למקטעים, צלילים מוכנים מראש, ניתוח שמע, מפה לדוגמה או ציונים.

- כפתור ״הוסף צליל״ יוצר צליל ליד מרכז המפה ופותח עורך לשם חופשי, צבע, גודל, עומק וזמן כניסה משוער (רשות). הצעות השמות הן קיצורי דרך כלליים בלבד.
- גרירה בעכבר, בעט או במגע מזיזה את הצליל. מקשי חצים מזיזים צליל ממוקד ב־1% מטווח המפה; Shift וחץ מזיזים ב־5%. שמאל וימין נשארים פיזיים גם בממשק RTL. למעלה מייצג גובה תדר נתפס גבוה, ולמטה נמוך.
- עומק (קרוב / אמצע / רחוק) משנה שקיפות, טבעת וצל בלבד; גודל הצליל נשלט בנפרד. תוויות נשארות אטומות וקריאות. תפריט בחירת צליל מאפשר לבחור גם צלילים חופפים.
- כפתור הביטול או Ctrl/Cmd+Z מחזירים עד 60 פעולות של המפה במהלך הביקור. בתוך שדה טקסט קיצור המקשים מפעיל את הביטול הרגיל של הדפדפן. ״התחל מחדש״ דורש אישור וניתן לביטול במהלך הביקור.
- הצלילים, מיקומיהם וכל מאפייניהם והכינוי נשמרים מקומית תחת `sound-lab:billie-jean:mix-map:v1`. רענון, מעבר נגן ויציאה וחזרה לשיעור שומרים את העבודה. היסטוריית הביטול אינה נשמרת לאחר רענון. אם אחסון הדפדפן חסום, מוצגת הודעה ואפשר להמשיך ליצור ולהוריד תמונה.
- ״שמור את מפת המיקס שלי״ מוריד PNG בגודל 2400×1600, עם כותרת השיר, האמן, הכינוי, צירים ומקרא עומק. התמונה נוצרת מהנתונים ב־Canvas, בדפדפן בלבד, עם הגופן העברי המקומי; ללא נגנים, פקדי עריכה או צילום iframe.

מימוש המודול נמצא ב־`src/mix-map/`: `index.js` מכיל את השיעור והאינטראקציות, `styles.css` את העיצוב המבודד, `model.js` את אימות הנתונים והשמירה, `player.js` את הנגנים ו־`export.js` את יצירת התמונה. לא היה במאגר מודול Mix Map קודם. החיבור לאתר משתמש בנתב ובמעטפת המשותפים, דרך `src/main.js` ו־`src/data/lessons.js`; אין תלויות חדשות או שרת.

### השמעה ומגבלות ספקים

הנגנים הרשמיים משתמשים ב־[אודיו האלבום ב־YouTube](https://www.youtube.com/watch?v=P_7q2RJtVQA) וב־[הרצועה ב־Spotify](https://open.spotify.com/track/1Rt3oh7shVSWj6q2MieDHa). השמעה אינה מתחילה אוטומטית. החלפת ספק מסירה את ה־iframe הקודם ועוצרת אותו, בלי לשנות את המפה. פס ההתקדמות, עצירה והמשך הם פקדי הספק; ב־YouTube מתווספים דילוגים של 5 שניות דרך ה־[IFrame Player API הרשמי](https://developers.google.com/youtube/iframe_api_reference). הם מוגבלים למשך השיר ומשמרים מצב עצירה; לפני הפעלה ראשונה הם מכינים מיקום ללא התחלת שמע. אם ה־API חסום, הנגן הטבעי והקישור החיצוני נשארים זמינים.

בבדיקת ההשמעה החיה בסביבת הפיתוח, סרטון YouTube שסופק החזיר קוד **150**, המצביע על איסור הטמעה מצד הספק (101 הוא קוד שקול). הממשק מציג הסבר בעברית וקישור ל־YouTube או מעבר ל־Spotify. לא ניתן להבטיח השמעה מלאה בתוך האתר מהקישור שסופק כאשר הספק חוסם הטמעה. ב־Spotify האנונימי נצפתה תצוגה מקדימה; זמינות ההשמעה המלאה והניווט תלויה בחשבון, במדינה, בדפדפן ובהגדרותיו, כפי שמתואר ב־[תיעוד ההטמעות של Spotify](https://developer.spotify.com/documentation/embeds/tutorials/troubleshooting). יש קישור חיצוני קבוע. לא קיימים פקדי דילוג מדומים ל־Spotify, ואין הורדה או אירוח של שמע.

בדיקות המפה נמצאות ב־`tests/mix-map.test.js` וב־`tests/browser/mix-map.spec.js` (עכבר, מגע, מקלדת, שמירה, Undo, אישור איפוס, אחסון חסום, רספונסיביות ויצוא PNG עברי). `tests/browser/mix-player.spec.js` בודק קריאות API, מצבי השמעה, מעבר ספקים, ניקוי וחסימת API באמצעות דימוי מבוקר; דימוי זה אינו הוכחה לזמינות מדיה חיה אצל ספק חיצוני.

## הרצת הבדיקות

```sh
npm run build
npm test
```

בדיקות היחידה בודקות 100 סבבים של כל מחולל שאלות. בדיקות Playwright רצות מול בניית הייצור ובודקות מצגת, מסך מלא, נתיבים, RTL, גדלי מסך, תזכורת שמיעה, אות שמע אמיתי דרך Web Audio, מניעת חפיפה, משוב, ניקוד, תרגול חוזר וניקוי משאבים. ב־Windows הן משתמשות ב־Edge המותקן; במערכות אחרות יש להתקין את דפדפן הבדיקה באמצעות `npx playwright install chromium`. תמונות הבדיקה נשמרות ב־`test-results` ואינן נכללות בפרויקט המפורסם.
